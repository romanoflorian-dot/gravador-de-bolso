# Gravador de Bolso

App criado para o curso de Arte Sonora de LV/PPGAV/EBA/UFRJ por Floriano Romano.

Grava pelo microfone do aparelho, corta o manuseio, trata o som, oferece um estúdio de música concreta (operações da era da fita) e exporta em WAV e MP3. Tudo é processado no próprio aparelho.

Versão completa (Full): https://romanoflorian-dot.github.io/gravador-de-bolso/

Versão resumida (Lite): https://romanoflorian-dot.github.io/gravador-de-bolso/lite/

O codificador de MP3 é o lamejs (LGPL-3.0), ver `LICENSE-lamejs.txt`.
